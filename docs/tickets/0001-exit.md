# 0001: Exit for copied positions

Not in v1. v1 is buy only; users sell by hand. The UI shows nothing about exits.

## Scope

- Time schedule: sell 1/4 at 4 h, 8 h, 1 d, 3 d after the copy buy. Per-user toggle.
- Optional band (10–50×) plus time schedule, as a DCL sub-band ladder. Remove filled sub-bands and withdraw wNEAR at once.

## Evidence

Beak repo: `research/2026-11-06_copytrade_exits.md` (Addendum 2), `research/2026-11-06_band_exits.md`.

## Open

- Bot power: in v1 only the owner can call `vault.sell`. Exits need a new vault version that lets the bot key sell (and, for bands, call DCL range methods). Each owner signs the switch.
